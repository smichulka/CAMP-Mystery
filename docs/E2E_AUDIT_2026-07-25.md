## Defects resolved

1. The Windows workflow assumed a nonexistent `master` branch instead of resolving the
   repository default branch.
2. Roblox Studio could not opt into the real DataStore adapter with a disposable test
   namespace.
3. Real-adapter retry exhaustion could not be exercised deterministically.
4. A failed player-leave profile save discarded the in-memory state instead of retaining
   it for bounded retries and shutdown handling.
5. GitHub Actions depended on a brittle external Rokit installer/API path and could skip
   the repository gate before tests ran.
6. The new operational paths lacked regression tests and repeatable operator guidance.
